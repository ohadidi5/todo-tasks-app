# 📋 רשימת משימות וקניות (Hebrew To-Do & Shopping List)

אפליקציית ווב מודרנית וקלילה בעברית לניהול משימות ורשימת קניות.

## ✨ מאפיינים
- **הוספת משימה:** שדה כתיבה עליון וכפתור פלוס (או מקש Enter).
- **סיום והעלמה (כמו ברשימת קניות):** לחיצה על הריבוע הקטן שלצד המשימה משמיעה צליל נעים, מציגה V, ומעלימה את המשימה בצורה חלקה מהרשימה.
- **אפשרות ביטול (Undo):** אם נלחץ בטעות, מופיע כפתור ביטול מיידי.
- **שמירה אוטומטית:** כל הנתונים נשמרים ב-`LocalStorage` של הדפדפן.
- **תמיכה מלאה ב-RTL ומובייל:** מותאם למחשב ולסמארטפון.

## 🚀 איך להפעיל
פשוט פתחו את הקובץ `index.html` בכל דפדפן!
